# Ветеринарный калькулятор дозировок

Небольшое адаптивное приложение на HTML, CSS и JavaScript без внешних зависимостей. Русский интерфейс, автоматические расчёты, светлая и тёмная темы с сохранением выбора. Поддерживает десятичную точку и запятую.

## Запуск

Из каталога репозитория выполните:

```sh
python3 -m http.server 8000
```

Откройте http://localhost:8000. Также можно выполнить `npm start`. Устанавливать npm-пакеты не нужно. Используйте HTTP-сервер, поскольку приложение загружает JavaScript-модули.

## Тесты

Требуется Node.js 18 или новее:

```sh
npm test
```

Тесты проверяют формулы, дробные и нулевые значения, недопустимый ввод, переполнение и потерю слишком малых значений.

## Формулы и ограничения

- Количество вещества (мг) = масса (кг) × дозировка (мг/кг).
- Объём (мл) = количество вещества (мг) ÷ концентрация (мг/мл).
- Масса и дозировка неотрицательны; концентрация строго больше нуля.
- Результаты отображаются с округлением до 6 значащих цифр. Очень малые и большие значения используют научную запись. Вычисления используют стандартные числа JavaScript с плавающей точкой.

Приложение проверяет математику, не назначает лекарства и не проверяет клиническую допустимость дозировки. Назначение, единицы, концентрацию, округление под шприц и способ введения проверяет ветеринар.
